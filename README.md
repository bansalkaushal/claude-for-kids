# 🤖 AI Agent Prompt Toolkit

> A free, shareable prompt toolkit for teen builders learning to create AI agents.

**Live site →** `https://bansalkaushal.github.io/claude-for-kids/`

---

## What's inside

14 copy-paste prompts for Claude, NotebookLM, Gemini, and any AI tool — covering:

- Learning any concept explained at your level
- Debugging broken agent code
- Designing an agent before writing a single line
- Mastering prompt engineering techniques
- Deep-diving framework docs in NotebookLM
- Planning your agent's logic flow
- Safety-checking your agent before sharing

## How to use

Open the live site and click any card to expand it. Hit **Copy** and paste straight into your AI tool.

## Stack

Pure HTML + CSS + JS. No frameworks, no build step, no dependencies. One file.

## Deploy your own

1. Fork this repo
2. Go to **Settings → Pages → Source → Deploy from branch → main → / (root)**
3. Your site is live in ~60 seconds
